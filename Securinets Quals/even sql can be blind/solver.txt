Step1:
extract all post bodies
	tshark -r blind_sqli.pcap -Y 'http.request.method == "POST"' -T fields -e http.file_data > post_bodies.txt

Step2:
decode them from base64 and remove username= and those

	while read line; do   echo "====";   echo "$line" | xxd -r -p | sed 's/%/\\x/g' | xargs printf '%b' | sed -n 's/.*username=\([^&]*	\).*/\1/p' | 	base64 -d; done < post_bodies.txt > payloads.txt


Step3:
then used a python code to extract the right character

	import re

	chars = {}

	with open("payloads.txt", "r", encoding="utf-8", errors="ignore") as f:
    	for line in f:
        	m = re.search(r"SUBSTR\(password,\s*(\d+)\s*,\s*1\)\s*=\s*'(.{1})'", line)
        	if m:
            	pos = int(m.group(1))
            	ch = m.group(2)
            	chars[pos] = ch

	for pos in sorted(chars):
    	print(chars[pos], end="")

	print()
